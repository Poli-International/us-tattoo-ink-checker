## 🎯 Overview

Screen tattoo ink ingredient lists against FDA MoCRA duties and California Prop 65 safe harbor levels. Free, seven languages, nothing leaves your browser.

**Category:** Studio Operations

This is a free, open-source widget from the [Poli International Widget Suite](https://poliinternational.com/tools/), a collection of practical tools for tattoo and piercing studios, artists, and clients. It runs entirely in the browser; no data is sent to a server.

---

## ✨ Features

- ✅ **MoCRA Tattoo Ink**
- ✅ **Prop 65 Tattoo Ink**
- ✅ **FDA Tattoo Ink Regulations**
- ✅ **Tattoo Ink Ingredient Check**
- ✅ **CAS Number Lookup**
- ✅ **NSRL MADL Safe Harbor**
- ✅ **Responsive Design**, works on desktop, tablet, and mobile.
- ✅ **Free & Open Source**, MIT licensed.

## 🚀 Installation

### Option 1: Use Online (Recommended)

No installation needed! Just visit:
**[https://poliinternational.com/tools/us-tattoo-ink-checker/](https://poliinternational.com/tools/us-tattoo-ink-checker/)**

### Option 2: Run Locally

This tool is pure HTML/CSS/JS, no build step. Clone the repo and open `index.html`:

```bash
git clone https://github.com/Poli-International/us-tattoo-ink-checker.git
cd us-tattoo-ink-checker
# open index.html in your browser
```
